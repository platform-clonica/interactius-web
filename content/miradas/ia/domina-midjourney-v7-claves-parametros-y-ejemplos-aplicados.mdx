Con la llegada de Midjourney V7, generar imágenes con un realismo casi fotográfico es más accesible que nunca. Esta versión ha dado un salto notable en tres aspectos clave: mejor interpretación de los prompts, texturas más creíbles y detalles mucho más coherentes (sí, incluso las manos). Pero para sacarle todo el partido, no basta con escribir cualquier cosa: hay que saber construir buenos prompts y hacerlo con intención.

## El punto de partida

Queremos generar una imagen tipo retrato. Empezamos con algo básico:

```
a woman portrait, neutral background, soft light
```

Este será nuestro punto de partida. Iremos aplicando ajustes para ver cómo mejora visualmente en cada iteración.

## ChatGPT como copiloto creativo

No siempre sabemos describir lo que imaginamos. Aquí es donde ChatGPT se convierte en una herramienta creativa increíble. Puedes pedirle que enriquezca tu prompt, que lo haga más visual, o que explore estilos concretos.

Prompt básico:
```
a woman portrait, neutral background, soft light
```

Reformulación con ChatGPT (más visual y detallado):
```
editorial portrait of a young woman wearing a linen blouse, neutral grey backdrop,
soft diffused light, 50mm lens, natural skin texture, cinematic tones
```

## Técnicas intermedias para optimizar tu prompt

### Aspect ratio (`--ar`)

`1:1` / `4:3` / `2:3` / `16:9` / `9:16`

Para retratos verticales clásicos: `--ar 2:3`

### Estilización (`--s`)

Indica cuánta libertad tiene Midjourney para interpretar el prompt:

- Valor bajo = más fidelidad al texto
- Valor alto = más creatividad visual

Para realismo: `--s 100`. Junto con `--style raw` lograrás un look más natural, sin filtros artísticos añadidos.

### Calidad (`--q`)

- `--q 1` — calidad estándar (más rápido)
- `--q 2` — alta calidad (más lento, más detalle)

### Versión (`--v`)

Siempre especifica `--v 7` para asegurarte de usar la última versión y sus mejoras.

## Novedades de Midjourney V7

### `--ow` (Omni-Reference Weight)

El parámetro ajusta el peso de una imagen de referencia en el resultado final, especialmente útil para mantener consistencia de estilo, personaje, objeto o ambientación en diferentes generaciones.

### `--p` (Personalización)

V7 introduce un modo de personalización que aprende de tus preferencias a medida que valoras imágenes. Cuantas más imágenes valoras, más afinado queda el modelo a tu estilo.

### Mejor coherencia de manos y anatomía

Una de las quejas históricas de Midjourney era la representación de manos. V7 ha mejorado significativamente este aspecto, aunque sigue siendo recomendable especificar explícitamente en el prompt cuando las manos son relevantes.

## Prompt final optimizado

Partiendo del ejemplo base, así quedaría el prompt completamente optimizado:

```
editorial portrait of a young woman wearing a linen blouse, neutral grey backdrop,
soft diffused light, 50mm lens, natural skin texture, cinematic tones
--ar 2:3 --s 100 --style raw --q 2 --v 7
```

## Conclusión

Midjourney V7 es la versión más potente y accesible hasta la fecha. La clave para dominarla no está en conocer todos los parámetros de memoria, sino en desarrollar un criterio visual claro: saber qué quieres generar antes de escribir el primer prompt. La IA es una herramienta; el criterio es tuyo.
